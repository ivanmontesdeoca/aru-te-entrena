# Aru te entrena

Base técnica del MVP para administrar alumnos, cobros, ejercicios, plantillas, rutinas y progresos.

## Desarrollo

```bash
pnpm install
pnpm dev
```

Comprobaciones:

```bash
pnpm typecheck
pnpm lint
pnpm build
```

La configuración de servicios externos está documentada en `docs/configuracion.md`.
